ABOUT THE PROJECT

Art discovery across modalities.

Images and descriptions can be matched with pretrained CLIP. Whisper turns speech into text before retrieval. The app also provides clearly labelled TF-IDF and pixel baselines for comparison.

Number references

Artwork numbers use a project-defined convention: sort artwork filenames case-insensitively and number them from one. This convention has not been verified against the dataset creator's intended audio alignment. Direct lookup is separate from speech recognition.

Evaluation

See the Evaluation page for measured results. Caption benchmarks describe performance on this collection, not general accuracy on unseen collections. Similarity scores are not probabilities. Speech Word Error Rate requires independently supplied reference transcripts.

Preparation

Models are downloaded explicitly, and image indexes are saved to disk before serving searches. Restarting the server reuses these indexes. Changing image files invalidates the relevant index.
